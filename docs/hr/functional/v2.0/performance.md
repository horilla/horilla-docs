# **Performance**

The Performance module covers goal tracking (objectives and key results), 360° feedback, meetings and bonus points. Open it from **Performance** in the sidebar.

## **Pages in this chapter**

| Page | Where | What it is for |
|---|---|---|
| [Performance Dashboard](/hr/functional/v2.0/performance/dashboard) | **Performance → Dashboard** | Objective, feedback and progress figures |
| [Employee Objectives](/hr/functional/v2.0/performance/objectives) | **Performance → Employee objective** | Objectives assigned to people |
| [Key Results](/hr/functional/v2.0/performance/key-results) | **Performance → Key Results** | The measurable results objectives are built from |
| [360 Feedback](/hr/functional/v2.0/performance/feedback) | **Performance → 360 Feedback** | Feedback cycles and anonymous feedback |
| [Meetings](/hr/functional/v2.0/performance/meetings) | **Performance → Meetings** | Performance meetings and minutes |
| [Bonus Points](/hr/functional/v2.0/performance/bonus-points) | **Performance → Bonus Points** | Points awarded to employees |
| [Performance Configuration](/hr/functional/v2.0/performance/configuration) | **Performance → Configuration** | Question templates, review periods, bonus point rules |

## **How the pieces fit**

1. **Key results** are defined first, each with a progress type and a target.
2. An **objective** groups one or more key results, and is assigned to people with managers and a duration.
3. **360 feedback** collects answers about an employee from their manager, subordinates and colleagues, using a **question template** and a **review period** from [Configuration](/hr/functional/v2.0/performance/configuration).
4. **Meetings** record performance conversations and their minutes.
5. **Bonus points** are awarded to employees, by hand or by rules set in Configuration.

::: info Scope
Pages are described as an administrator sees them. Creating objectives, feedback and meetings, answering feedback and awarding points change real records and were not exercised. Who sees whose feedback, and what an anonymous submission reveals to each role, was not verified, so it is not stated.
:::
