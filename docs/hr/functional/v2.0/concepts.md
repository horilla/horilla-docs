# **How Horilla HR Fits Together**

This page explains the ideas that appear in every chapter. It is written for an administrator setting up the system for the first time.

## **Set up in this order**

1. **Company and structure** in [Settings](/hr/functional/v2.0/settings): [Companies](/hr/functional/v2.0/settings/companies), [Departments](/hr/functional/v2.0/settings/departments), [Job Positions](/hr/functional/v2.0/settings/job-positions) and [Job Roles](/hr/functional/v2.0/settings/job-roles).
2. **Formats and defaults** in [System Preferences](/hr/functional/v2.0/settings/system-preferences): badge ID prefix, currency, date and time format.
3. **Schedules and policies**: [Work Schedules](/hr/functional/v2.0/employee/work-schedules), [Attendance Rules](/hr/functional/v2.0/attendance/attendance-rules), [Leave configuration](/hr/functional/v2.0/leave/configuration) and [Public Holidays](/hr/functional/v2.0/leave/public-holidays).
4. **Employees**: [add them](/hr/functional/v2.0/employee/employees) with work information that points at the structure above.
5. **Access**: [Roles and Permissions](/hr/functional/v2.0/settings/roles-permissions).
6. **Day-to-day modules**: [Attendance](/hr/functional/v2.0/attendance), [Leave](/hr/functional/v2.0/leave/), [Payroll](/hr/functional/v2.0/payroll), [Recruitment](/hr/functional/v2.0/recruitment), [Onboarding](/hr/functional/v2.0/onboarding), [Offboarding](/hr/functional/v2.0/offboarding), [Performance](/hr/functional/v2.0/performance), [Project](/hr/functional/v2.0/project), [Assets](/hr/functional/v2.0/asset), [Tickets](/hr/functional/v2.0/helpdesk) and [Reports](/hr/functional/v2.0/report).

## **Ideas used everywhere**

| Idea | Meaning |
|---|---|
| Badge ID | The employee's visible ID, built from the prefix in System Preferences |
| Work information | The record linking an employee to company, department, job position, job role, shift, work type and reporting manager |
| Reporting manager | The employee who approves that person's requests |
| Company-specific settings | Settings apply to the company shown in the banner at the top of Settings |
| Filter, Actions, Create | Most list pages share these three controls at the top right |
| Tabs and views | Many pages offer a list view and a card or pipeline view; the app remembers the last tab you used |

::: info Scope
This documentation covers what an administrator sees. How the same screens look to other roles was not tested.
:::
