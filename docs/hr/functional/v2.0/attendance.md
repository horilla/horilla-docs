# **Attendance**

The Attendance module records when people work: check-in and check-out, the daily record built from them, corrections and requests, overtime, late arrivals and early departures, and monthly totals. Open it from **Attendance** in the sidebar.

|---|---|---|

## **How the pieces fit**

1. **Settings → Attendance Rules** decides how attendance is captured (the **Check In** button, biometric devices, IP limits and so on).
2. Each check-in and check-out becomes an entry in the [Check-in / Check-out Log](/hr/functional/v2.0/attendance/check-in-check-out-log), and the day's entries roll up into one record in [Attendances](/hr/functional/v2.0/attendance/attendances).
3. An attendance record is *validated* (confirmed) either by a person or automatically under the [Time Policies](/hr/functional/v2.0/attendance/time-policies). Overtime is approved separately.
4. If a record is missing or wrong, an [attendance request](/hr/functional/v2.0/attendance/attendance-requests) asks for a correction.
5. [Daily Work Status](/hr/functional/v2.0/attendance/daily-work-status) and [Monthly Summary](/hr/functional/v2.0/attendance/monthly-summary) summarise the result, and the dashboard charts it.

::: info Scope
Pages are described as an administrator sees them. What employees and managers see is not covered in this edition. Clicking the **Check In** button was not exercised, because it creates a real attendance record.
:::
