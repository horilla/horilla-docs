# **Integrations**

The **Integrations** section connects Horilla HR to other services. Credentials are entered here but are never reproduced in this documentation, so this page lists field names only.

| Page | What it shows |
|---|---|
| Google Drive Backup | Backups to Google Drive; the demo shows only *Only work with postgresql database.* |
| LinkedIn | An **Enable Linkedin** switch (off on the demo) for the recruitment integration |
| LDAP | **Ldap Server, Bind Dn, Bind password, Base Dn** and **Save** |
| Google Meet | An **Enable Google meet** switch (off on the demo) |
| WhatsApp | An **Enable WhatsApp** switch (off on the demo) |

::: info Not tested
None of these integrations were enabled or connected, and no credentials were entered.
:::
