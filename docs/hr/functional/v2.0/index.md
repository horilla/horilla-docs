# **Horilla HR Functional Guide (v2.0)**

This guide explains how to use Horilla HR day to day: what each screen is for, what each control does, and what to expect afterwards. It is written for people who run and use the product, not for developers. For installation, settings files and architecture, see the [technical documentation](/hr/technical/v2.0/).

::: info Version reviewed
This guide was written against **Horilla HR 2.1.8** (the version shown at the bottom of the sidebar), using the public demo at `hr.demo.horilla.com` with the demo's data. Screenshots are taken at 1920 × 1080.
:::

## **Who this edition is written for**

This first edition describes Horilla **from the administrator's point of view**: every screen and action is described as an administrator sees it. Employees, managers and other roles see a subset of these screens, and some pages behave differently for them. Where a page notes that other roles are not covered, that part has not been verified yet and is planned for a later edition.

## **How to read this guide**

If you are new to Horilla, read in this order:

1. [Getting started](/hr/functional/v2.0/getting-started): sign in, find your way around, and use the top bar.
2. [Dashboard](/hr/functional/v2.0/dashboard): the page you land on, and what each number and chart means.
3. The module you need, from the sidebar of this guide.

## **Conventions used**

- **Bold** is a label you can see and click, for example **Customize**.
- Numbers in a screenshot match the numbered explanation next to it.
- A path such as **Employee → Employees** means: open **Employee** in the sidebar, then **Employees**.
- Figures such as employee counts come from the demo's sample data and will differ on your own installation.
