# **Glossary**

| Term | Meaning |
|---|---|
| Allocation | Leave days granted to an employee |
| Asset batch | A group of assets of one category added together |
| Badge ID | Visible employee ID, for example PEP00 |
| Candidate | A person who applied for a job |
| Check-in / Check-out | Recording the start and end of a work day |
| Department | A group of employees with an optional manager |
| Helpdesk ticket | An internal request raised by an employee |
| Job position | A title within a department |
| Job role | A specific role under a job position |
| Late come / early out | Arriving after or leaving before the scheduled time |
| Offboarding | The exit process for a leaving employee |
| Onboarding | The process of bringing a new hire into the company |
| Payslip | A document showing an employee's pay for a period |
| Pipeline | Stages a record moves through, for example candidates in recruitment |
| Role | A named set of employees sharing access (Settings) |
| Shift | A scheduled work time pattern |
| Work type | How an employee works, for example office or remote |
