# **Offboarding**

The Offboarding module manages employees leaving: the notice period, exit tasks and the stages from notice to farewell. Open it from **Offboarding** in the sidebar.

## **Pages in this chapter**

| Page | Where | What it is for |
|---|---|---|
| [Offboarding Dashboard](/hr/functional/v2.0/offboarding/dashboard) | **Offboarding → Dashboard** | Exit figures and trends |
| [Exit Process](/hr/functional/v2.0/offboarding/exit-process) | **Offboarding → Exit Process** | Employees moving through exit stages |
| [Offboarding Rules](/hr/functional/v2.0/offboarding/rules) | **Settings → Offboarding** | Resignation requests and notice period |

## **Starting an exit is not the same as removing access**

Adding an employee to the Exit Process records the notice period and tracks tasks. The pages in this chapter do not show that it disables the employee's sign-in, archives their employee record, settles payroll or collects assets. Those effects were not observed, so do not assume them. The dashboard does include an **Unreturned Assets** widget, which suggests asset return is tracked, but how it is enforced was not tested.

::: info Scope
Pages are described as an administrator sees them. Adding employees to the pipeline, changing stages or task statuses, and changing rules affect real people and were not exercised.
:::
