# **Reports**

The Reports module has two tools under one menu: **Standard Reports**, a catalog of ready-made reports, and **Explorer**, an ad-hoc pivot tool for each module. Open it from **Reports** in the sidebar.

## **Pages in this chapter**

| Page | Where | What it is for |
|---|---|---|
| [Standard Reports](/hr/functional/v2.0/report/standard-reports) | **Reports → Standard Reports** | 34 curated reports with metrics, charts and detail tables |
| [Explorer](/hr/functional/v2.0/report/explorer) | **Reports → Explorer** | Pivot tables and charts built from a module's data |

## **Which one to use**

The Explorer page itself says it: *Ad-hoc pivots per module. Use Standard Reports for curated KPIs, charts, and export.* Use a standard report when one already answers your question, and the explorer when you need to slice a module's data your own way.

::: info Scope
Pages are described as an administrator sees them. Exporting reports and creating saved views or schedules were not exercised.
:::
