# **Project**

The Project module tracks projects, the tasks inside them, and the hours people log against that work. Open it from **Project** in the sidebar.

## **Pages in this chapter**

| Page | Where | What it is for |
|---|---|---|
| [Project Dashboard](/hr/functional/v2.0/project/dashboard) | **Project → Dashboard** | Project and task figures |
| [Projects](/hr/functional/v2.0/project/projects) | **Project → Projects** | The project list, and each project's stage board |
| [Tasks](/hr/functional/v2.0/project/tasks) | **Project → Tasks** | Every task across projects |
| [Timesheets](/hr/functional/v2.0/project/timesheets) | **Project → Timesheet** | Hours logged against tasks |

## **How the pieces fit**

1. A **project** has managers, dates and a status.
2. Each project has **stages** (for example *Todo, In Progress, Completed*) that form its task board.
3. **Tasks** sit in a stage, belong to a project, and have managers, members, dates and allocated hours.
4. **Timesheets** record the hours spent on a task by an employee.

::: info Scope
Pages are described as an administrator sees them. Creating projects, tasks and timesheets, importing, archiving and deleting change real records and were not exercised.
:::
