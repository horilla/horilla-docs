# **Requests & Allocation**

This page is meant for asset requests and for allocating assets to employees. Open it from **Assets → Requests & Allocation**. The page title is **Asset Requests & Allocations**.

::: warning Did not load in the demo
In the demo the page opens as an empty screen: the header and menu appear, but the page body is blank. The same happened when it was opened from the **Assets** tile of the main dashboard's **Pending Approvals**. Because of this, its tabs, filters, forms and the request and allocation workflow could not be observed, and this guide does not describe them.
:::

What can be seen elsewhere:

- The [Asset Dashboard](/hr/functional/v2.0/asset/dashboard) has a **Request Status** widget showing 3 requests split into **Requested, Approved** and **Rejected**.
- The main [dashboard](/hr/functional/v2.0/dashboard) has an **Assets** tile under **Pending Approvals**, which links here.
- [Asset History](/hr/functional/v2.0/asset/history) lists assets already allocated, with their return status.
