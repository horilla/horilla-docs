# **Leave**

The Leave module handles time off: the leave types your organisation offers, the balance each employee holds, the requests employees raise against those balances, and the rules that decide who approves them. Open it from **Leave** in the sidebar.

## **How the pieces fit**

1. An administrator defines **leave types** in [Configuration](/hr/functional/v2.0/leave/configuration).
2. A leave type is given to employees through [Leave Balances](/hr/functional/v2.0/leave/leave-balances). An employee can only request a leave type they hold a balance for.
3. The employee requests leave in [My Leave Requests](/hr/functional/v2.0/leave/my-leave-requests); an administrator can also create a request for them in [Leave Requests](/hr/functional/v2.0/leave/leave-requests).
4. The request is approved, rejected or cancelled. [Restricted Leave Periods](/hr/functional/v2.0/leave/restricted-leave-periods), [Public Holidays](/hr/functional/v2.0/leave/public-holidays) and approval rules shape what is allowed.

::: info Compensatory leave
The demo includes a **Compensatory Leave Type**, but the **Compensatory Leave Requests** page is not in the Leave menu because the feature is switched off in **Settings → Leave Rules**. See [Leave Rules](/hr/functional/v2.0/leave/leave-rules).
:::

::: info Scope
Pages are described as an administrator sees them. What employees and managers see on the same pages is not covered in this edition.
:::
