# **Assets**

The Assets module tracks company equipment: what exists, which batch it came in, who has it, and its history. Open it from **Assets** in the sidebar.

## **Pages in this chapter**

| Page | Where | What it is for |
|---|---|---|
| [Asset Dashboard](/hr/functional/v2.0/asset/dashboard) | **Assets → Dashboard** | Asset status, age and allocation figures |
| [Assets](/hr/functional/v2.0/asset/assets) | **Assets → Assets** | The asset list, grouped by category |
| [Asset Batches](/hr/functional/v2.0/asset/batches) | **Assets → Asset Batches** | Batch numbers that group assets |
| [Requests & Allocation](/hr/functional/v2.0/asset/requests-allocation) | **Assets → Requests & Allocation** | Asset requests and allocating assets |
| [Asset History](/hr/functional/v2.0/asset/history) | **Assets → Asset History** | Who held each asset, and its condition on return |
| [Asset Rule](/hr/functional/v2.0/asset/rule) | **Settings → Assets** | Asset fines |

::: warning Requests & Allocation did not load
In the demo, **Assets → Requests & Allocation** opens as an empty page, so the request-and-allocation workflow could not be observed or documented. See [that page](/hr/functional/v2.0/asset/requests-allocation).
:::

::: info Scope
Pages are described as an administrator sees them. Creating, importing, duplicating and deleting assets and batches change real records and were not exercised.
:::
